# VirtualLife

[English](README.md) | **Русский**

VirtualLife — экспериментальная симуляция небольшого живого мира, созданная с нуля на Python.

В текущей версии клетка учится находить еду на сетке с помощью простого алгоритма Q-learning.

## Как это работает

- Мир представляет собой сетку размером `20 x 20`.
- На сетке размещаются клетка и еда.
- Состояние клетки — это расстояние до еды.
- Клетка может двигаться вверх, вниз, влево и вправо.
- За движение даётся небольшой штраф, за столкновение со стеной — больший штраф, а за найденную еду — награда.
- После обучения выученное поведение показывается в окне Matplotlib.

## Установка

Согласно настройкам проекта требуется Python версии 3.14 или новее.

```bash
git clone https://github.com/winowne/VirtualLife.git
cd VirtualLife
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

В Windows виртуальное окружение запускается так:

```bash
.venv\Scripts\activate
```

## Запуск

```bash
python main.py
```

`main.py` запускает проект по очереди:

1. `train.py` обучает Q-таблицу в течение 3000 эпизодов.
2. Таблица сохраняется в `q_table.pkl`.
3. `demo.py` открывает визуализацию и запускает обученную клетку на 200 шагов.

Файл `q_table.pkl` содержит локальные данные обучения и игнорируется Git.

## Параметры обучения

Основные параметры находятся в `agent.py`:

| Параметр | Значение | Назначение |
| --- | ---: | --- |
| `epsilon` | `1.0` | Вероятность случайного действия в начале обучения |
| `gamma` | `0.95` | Важность будущих наград |
| `alpha` | `0.1` | Скорость изменения Q-таблицы |

В `train.py` обучение проходит за `3000` эпизодов. После каждого эпизода `epsilon` уменьшается в `0.995` раза, но не опускается ниже `0.05`. Один эпизод длится не больше `200` шагов.

Чтобы начать обучение полностью заново, удалите `q_table.pkl` и снова запустите `main.py`.

## Запуск отдельных частей

Обычно достаточно запустить весь проект:

```bash
python main.py
```

При необходимости части проекта можно запускать отдельно:

```bash
python train.py
python demo.py
```

Сначала запускайте `train.py`, если Q-таблица ещё не создана или была удалена. Затем запускайте `demo.py` для просмотра результата.

## Что происходит во время запуска

Во время обучения в терминал выводится суммарная награда каждого эпизода. Значения могут меняться в разные стороны из-за случайных действий агента.

После обучения открывается окно визуализации:

- тёмные клетки — свободное пространство;
- белая клетка — агент;
- красная клетка — еда.

Для завершения демонстрации закройте окно Matplotlib или остановите программу сочетанием `Ctrl+C` в терминале.

## Если окно не открывается

На Linux может понадобиться графический backend Matplotlib. Если программа запускается на сервере без графического интерфейса, визуальное окно открыть нельзя. В таком случае обучение можно запустить отдельно:

```bash
python train.py
```

Если зависимости установлены не в активное виртуальное окружение, установите их так:

```bash
python -m pip install -r requirements.txt
```

## Ограничения текущей версии

- У агента пока только одна клетка.
- Тело клетки фактически состоит из одной ячейки.
- Поля `hunger` и `health` подготовлены в классе `Cell`, но пока не участвуют в награде и состоянии.
- Состояние содержит только смещение до еды и не учитывает историю движений.
- Еда появляется случайно, а препятствий и других организмов пока нет.
- Обучение и демонстрация запускаются при импорте соответствующих файлов, поэтому `main.py` использует их как последовательные этапы.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Запускает обучение и визуализацию по очереди |
| `env.py` | Описывает мир, клетку, еду, движение, награды и сетку для отображения |
| `agent.py` | Хранит Q-таблицу и выбирает действия |
| `train.py` | Обучает агента и сохраняет `q_table.pkl` |
| `demo.py` | Показывает обученного агента через Matplotlib |
